# ANNDI BLOCK — protótipo 0.1

Este pacote contém o primeiro protótipo visual responsivo do ANNDI BLOCK.

## O que funciona
- Interface adaptada a telas de celular.
- Botão que alterna o estado de demonstração.
- Layout inicial e áreas planejadas para os recursos.

## O que ainda não funciona
- Não bloqueia anúncios.
- Não intercepta tráfego de rede.
- Não filtra anúncios do YouTube.
- Não é uma extensão Safari/Chrome instalável.

## Como visualizar pelo celular
1. Extraia o arquivo ZIP.
2. Hospede a pasta em um serviço de hospedagem estática HTTPS (por exemplo, GitHub Pages).
3. Abra o endereço no Safari ou Chrome.
4. No iPhone, use Compartilhar > Adicionar à Tela de Início para criar um atalho.
